## One fixed LINEAR_RBF_RIDGE recipe

For each native mature annual cohort:

1. Select the original canonical ordered125 features as a float64 matrix using the old numeric convention, replacing nonfinite values with NaN. Reject an entirely missing training column; keep125 dimensions, with no dropped columns or added missingness indicators. Fit SimpleImputer(strategy='median', keep_empty_features=True) on training rows only.
2. Fit StandardScaler(with_mean=True, with_std=True) on imputed training only. Retain its125 standardized columns as the linear design block.
3. Separately for each original seed101,202,303, fit RBFSampler(gamma=1.0/125.0, n_components=512, random_state=seed) on that standardized matrix. Gamma is the explicit numeric constant, never 'scale'. Fit a second StandardScaler(with_mean=True, with_std=True) on the resulting512 training basis columns.
4. Concatenate original standardized linear125 columns, followed by standardized RBF512 columns. Fit Ridge(alpha=30.0, fit_intercept=True, solver='svd', copy_X=True, positive=False) in float64 on original unrounded target_rank_21 float values, preserving row order and old Ridge's equal per-row loss weights. The fixed design has637 columns. No query weighting, bootstrap, clipping, relevance rounding, target calibration, search or early stopping.
5. Transform native/common inference using the corresponding mature native imputer and both scalers, then predict each of the three seed pipelines. Average raw predictions in seed order101,202,303 with explicit float64 accumulation/result. No percentile averaging, stacking, score clipping or combination with XGB.

The projection matrix and phase offsets must have identical hashes across all years/vintages for a given seed, because the feature dimension and numeric gamma are frozen. The scaler states remain learned separately from each native mature cohort. Do not pool snapshots or freeze their observed consensus; that would test a different treatment.

512 is the smallest power-of-two compute budget at least four times125. It is a heuristic capacity budget chosen before outcomes, not a quality-optimized dimension. Gamma1/125 expresses the exponent as mean squared standardized distance per original feature; correlations and tails may make that scale imperfect. Alpha30 reuses old Ridge/additive regularization with unit-scaled design columns. SVD is explicitly selected for numerical stability of correlated designs, with increased cost reported. Standardizing the RBF basis changes the induced metric, so the candidate is a Ridge model over a linear-plus-RBF expansion, not exactly pure RBF kernel ridge. The [RBFSampler1.8 documentation](https://scikit-learn.org/1.8/modules/generated/sklearn.kernel_approximation.RBFSampler.html) and [Ridge1.8 documentation](https://scikit-learn.org/1.8/modules/generated/sklearn.linear_model.Ridge.html) describe these mechanisms.

The linear125 block embeds the old Ridge function class: zero RBF coefficients make the old linear model admissible with the same alpha/intercept. This does not guarantee that the fitted model has at least its predictive quality, or that either matches XGB out of sample. The added basis aims to represent joint nonlinear relationships missing from linear/additive recipes.

At fixed finite design, Fourier coordinates are smooth in exact arithmetic and regularized Ridge coefficients depend linearly on target values. Unrounded target_rank_21 avoids additional integer relevance rounding, but percentile ranks themselves can jump under source-return reorderings. Native missingness flips, medians/scalers and near-tied score ordering remain potential discontinuities. Do not claim the full raw-data pipeline is continuous. Preserve and report these effects; do not silently add semideviation, winsorization or new missingness handling. StandardScaler keeps tails, and bounded cosine coordinates do not guarantee useful extrapolation or exact finite-precision continuity.

# R0-G — Read-only as-of label/pair-change audit preregistration
**2026-10-08. Frozen before inspecting newly derived label-pair outcomes.**

**Motivation:** Prior real ETF forensic reports ~0.047–0.070% changes in integer XGB training labels, but such a rowwise difference is not equivalent to the number of `rank:pairwise` ranking-pair reversals or tie changes. R0-F synthetic 360-tree probe shows one actual *ordinal reversal* can propagate to many split changes. Before considering any new rank loss/label-stabilization method, measure real ordinal/tie transitions **without retraining any existing model**.

**Fixed data**: existing frozen `yfinance-repeatability-v1-raw.zip` (Repeat1 vs Repeat3), 149 original ETFs in both, same calendar, adjusted Open, historical 2004–2026. Produce monthly `signal_date` as last common trading day of each calendar month, `entry_date` next trading session, `exit_date_h` entry+21 and optionally 63 trading sessions. 149 ticker returns `Open[exit]/Open[entry]-1`, with missing dates/invalid bars excluded *symmetrically* and explicitly counted. Use original source `source_only/kernel.py:add_labels`: `rank(pct=True)` by signal date, `round(100*pct)` to integer using NumPy/pandas equivalent rounding. No changes to original labels/hyperparameters or input.
 
**Fixed measurement:** for each calendar-month query having eligible labels in both vintages: number of ETF integer-grade changes; number of unordered ETF pairs (up to 149 choose 2) with strict relative-grade sign reversals (+ to −); number of transitions involving a tie (0 to ± or ± to 0); raw return rank sign flips and near-equal-return gaps; whether altered labels affect the top 10% by grade. Aggregate per month and for 2017, 2020, 2023, 2026 cutoffs using *mature* monthly training rows only. DO NOT claim old "same rows" if current reconstruction does not match exact precomputed eligibility; this protocol reconstructs **price-derived label component only**, not the full 125-feature-eligible training cohort. No inference/capital/CAGR replay.

**Decision/stop:** identify whether label-change sensitivity in R0-F resembles strict rank reversal, tie transitions, or both in authentic Yahoo vintages. If most changes represent ties only, report that; do **not** infer all changed label values caused gradient changes, and do **not** tune label bins (L50 already tested/worsened) or optimize on Original149. Results are diagnostic on burned development vintages, not new OOS evidence. If no authentic matched corpus, stop.

**Audit:** source zip SHA256; counts of months and valid ETF rows; one-to-one matching of calendar and returns; output CSV/JSON and analytic source to support bundle/GitHub Test research branch only.

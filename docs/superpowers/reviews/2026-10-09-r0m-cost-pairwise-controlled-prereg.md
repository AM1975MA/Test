# R0-M — Cost-band pairwise objective, controlled three-arm synthetic test (pre-result registration)
**2026-10-09 · AM1975MA/Test · research/v2-xgb-immutable-checkpoints-20261008 · synthetic only**

## Existing evidence and boundaries
R0-J on frozen Repeat1/3 149 ETF Yahoo confirms eight strict 21d pair inversions with return gap <=0.0116 bp and 7/7 tie transitions; a **fixed 20 bp return band** excludes 88,417 of 2,333,613 (~3.79%) prior pair comparisons while no large top-decile-vs-bottom-quartile pair is eliminated. There are 14 band-status flips between vintages. Band 20 bp is **a proposed economic anchor** based on 0.1% buy + 0.1% sell assumptions, not proof that the incremental swap cost is always 20 bp, nor an optimized edge. R0-K rank:ndcg can become more stable while losing synthetic top-5 accuracy; does not pass joint gate. R0-L `cost_pairwise.py` is an isolated proof that XGBoost 3.1.3 accepts full-pair diagonal gradients/Hessians. It is not canonical XGBoost `rank:pairwise`, and its group-pair weighting, sampling and Hessian approximation differ.

## Exact new falsification task (locked before fit)
**Three arms, not a parameter sweep**: (1) original `rank:pairwise` (unchanged params); (2) *unmasked* full-pair custom logistic objective `fee_band=0`, controlling for custom loss/sampler; (3) identical full-pair custom logistic objective with `fee_band=.002` (20 bp on synthetic 21d return units). Thus compare **masked vs unmasked** to isolate effect of margin; compare each to native only as model quality reference, NOT as a one-factor causal contrast.

- **Two new synthetic worlds** A/B RNG seeds `20261103` and `20261104` (not R0-E/F/H/K worlds), original R0-H nonlinear functions, 36 query groups × 40 rows for fit and 12 held evaluation groups × 40 rows; 125 dimensions. Rescale latent training return to `0.035 * latent` in each group; grade integer relevance from exact within-group percentile rank 0–100 as canonical. Ensure one pair of adjacent middle-ranked training rows is made nearly tied at `±5e-7` around their mean return, without changing their order; derive **all** grade labels from this corrected return ordering, not original latent if ties altered. Keep eval ground-truth latent unchanged. Synthetic return units are not actual ETF returns.
- **Three scenarios** for each world/arm/seed: (a) baseline, (b) X-only standardized-feature additive jitter σ=2.5e-6, all returns and integer grades unchanged, (c) y-only cross-price revision swaps the two almost identical mid-rank returns (exactly one strict true return-order/grade pair reversal) while keeping feature X byte-identical. Log the two return gaps and that the swapped pair is masked at 20 bp. **Do not modify/swap pairs after observing model results.**
- Original 3 seeds `101,202,303`, `rank:pairwise`, `max_depth=4`, `learning_rate=.035`, `subsample=.85`, `colsample_bytree=.8`, `min_child_weight=8`, `reg_lambda=8`, `reg_alpha=.1`, `tree_method=hist`, `nthread=1`, **360** rounds per Booster. Custom objective arms inherit identical tree settings and use `QuantileDMatrix` with explicit query groups. No adjustment of learning rate, leaf Hessian or alpha after outcomes.
- Exactly **2 × 3 arms × 3 scenarios × 3 seeds = 54 boosters**. Save score arrays and diagnostics. One trial of these seeds/worlds; do not substitute an easier world or add a 5bp/10bp search.
- **Primary outcome per world**, with paired three-seed ensemble: Top1 prediction agreement baseline vs X-only and vs y-only over 12 held groups, baseline and perturbed Top1 actual synthetic Top5 and exact-winner hits, NDCG@5 and rank-MAD; save differences masked minus unmasked and compare original native for reference. Treat failure of top-tail capture or X-only instability as **NO GO**. No post hoc average hides a world-specific failure.
- Validate in TDD tests: group pointers, 20bp actual return gap sign, exactly one pair reversal, masking excludes it and leaves top-vs-bottom pairs, X-only changes no labels, y-only changes no features, finite Hessian, no all-constant ensemble scores. Confirm custom gradient Hessian scaling differs from native and label this.
- No use of Original149/EU120 data in fitting, no portfolio CAGR, no parameter promotion to `Etf_trader`; synthetic success merely permits a *separate* preregistered genuine as-of financial challenge with fully matched V2 and downside/tail safeguards.

# COMPACT21_FEATURE_ABLATION_V1 — frozen before any candidate fit

The primary failure is prediction disagreement when the same historical bars are acquired again. The original three frozen TI panels and annual BASE XGB are used. No label, cutoff, snapshot pair, eligibility, model parameter, seed, negative-feedback, Compact63/Tail, MA3, or downstream portfolio code changes. The 30-feature eligibility test and training cohort selection occur **before** a mask; the 125-column ordered model schema remains unchanged and every selected column becomes NaN in annual training and both native and repeat-2 common inference. BASE exact retained-vector controls pass before candidates. Each annual/vintage candidate is independently refit with byte-exact predictions and metadata.

Four masks are fixed from source-only drift diagnostics and transform mechanics, before seeing their predictive outcomes. Earlier learner, semideviation, blockbag and RBF trials on these same three snapshots informed this research question, so this remains exploratory development analysis:

1. `DOWNVOL9`: downvol21/63/126, each raw, `_pct`, `_dev` (9 columns). The expanding annual year/pair drift table records 196 missing-mask changes in each representation (588 across these nine columns), all within this family. These are repeated appearances of a much smaller set of source-level events, not 588 independent events. The features contain a discontinuity when the count of negative returns straddles the minimum threshold.
2. `ROBUST_DEV33`: every `_dev` feature (33 columns). The per-date median/MAD division may amplify tiny source differences. This mask asks whether that representation contributes instability or predictive signal.
3. `CROSS_SECTION_PCT46`: every `_pct` feature (46 columns). Cross-sectional rank is discontinuous near ties and may make a tiny bar revision a discrete feature revision.
4. `HIGH_NOISE_COMPACT`: the 22 columns in downvol21/63/126, vol_ratio_21_126, skew63, kurt63 (raw, percentile, robust deviation), plus sign_entropy63 and positive_frac63 (raw and percentile). These were chosen from large IQR-normalized source drift and tail/event sensitivity. Its overlap with other masks is intentional; effects are descriptive, not additive.

Primary evaluation: all 114 paired common-inference months across 1–2, 1–3, 2–3; native Top1 disagreement per pair; common rank disagreement; then 113 mature quality dates, by vintage and overall, using realized selected-ticker return percentile and Precision@5. Stability pilot requires ≥25% reduction of both disagreement metrics against BASE and no worse pair. Near repeatability requires native Top1 disagreement ≤5% and common rank disagreement ≤10% of BASE for **each** pair. Quality similarity requires aggregate and each-vintage Top1 realized percentile ≥95% BASE, aggregate Precision@5 ≥95% BASE, and the one-sided paired block-bootstrap lower 95% bound for quality difference greater than −5% BASE primary. These are descriptive development gates after prior adaptive trials, not fresh-holdout significance. No automatic production adoption or CAGR test is implied. A plausible winner must still survive fresh independent acquisitions and a forward mature holdout before unchanged full-strategy replay.

Changing the mask changes XGB's split opportunity and missing-value routing; this trial measures the whole retrained learner under that mask. Because labels also drift across acquisitions, no feature mask alone is assumed to solve all instability. We report all four fixed variants regardless of outcome.

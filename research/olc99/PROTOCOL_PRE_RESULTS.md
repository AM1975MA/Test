# OLC99 — Second stage economic Top10 + independent matched-state allocation

**Research-only protocol frozen before execution on 12 Nov 2026.** Original OLC19, OLC67 and repository main remain unmodified. All historical windows through first July 2026 are repeatedly researched and do **not** constitute a virgin out-of-sample holdout.

## Identity and gates
- Primary selectors Return125/ET/XGB/memory/FUSION and native TOP2_CONTEXT_REVALUE scores are not retrained. Universe, active monthly events, V6 exposure, FAST_LOCK3, stop friction .001 stay unchanged.
- Shortlist is the top ten original FUSION ETFs among eligible rows at each signal. Baseline pair is highest two original contextual scores *within that frozen shortlist*. Compare exact original native selected pair for all months.
- Stage 1 (out-of-time expanding) predicts each candidate's *next opening-to-opening log return relative to Top10 median*, on same historical candidates, using only signal-known ranking and lagged market price features. Clipped train labels [-0.25,+0.25] to reduce domination by outliers; **the evaluation outcomes are never clipped**. Require 24 completed prior months and train only on events with index <=t-2. Ridge alpha=100 with train-only median imputation and standardization. Equal per-month sample mass. No ticker ID and no future returns as features.
- Stage-1 alternatives, specified before outcomes: E0 original contextual pair (control), E1 80% contextual Top10 rank score + 20% predicted economic rank score, E2 65% contextual rank + 35% predicted economic rank. Before training warmup both return E0. E1 is predesignated primary for allocation; E2 is a diagnostic, not to be selected post-hoc by CAGR.
- Stage 2 holds fixed E1 Top2 and DELAY3. For each monthly decision, clone one actual on-policy OLC19 pre-trade accounting state (cash/positions/stop locks/targets/etc). On each clone, simulate weights [0%,25%,50%,75%,100%] until the following event with the original FAST_LOCK3. Labels are known only after maturity and are admitted at t-2. Two allocation policies: P (prior-only mean of same-state 100%-minus-0% logbp), M (Ridge alpha=100 on pairwise ex-ante features to predict same effect); deterministic weight w=0.5+0.5*tanh(mu/sigma), clipped 0..1, with sigma the historical mature sample standard deviation floor 100 logbp. Minimum 24 labels; otherwise fallback 50/50. *The 0/100 end points are allowed, not forced.*
- Matched-state counterfactuals are diagnostic and used only as already-mature training labels. Every calendar month actually follows only its chosen branch. On-policy state is carried forward. Compare P to M with the same selection, DELAY3, market and costs.
- Controls: OLC19 CONTEXT/50-50/IMMEDIATE, CONTEXT/50-50/DELAY3; E1/50-50/DELAY3; E1/P/DELAY3; E1/M/DELAY3; plus OLC67 archived risk-oriented candidate, which uses different minvar weights. Fees 0.001 and 0.003, no change to risk guardrails.
- Metrics: monthly 21d Top2 static opening return (not CAGR), precision on next top-quintile, NDCG@10, daily native CAGR and maximum drawdown MAIN 2021-24 and FULL Feb2019-Jul2026, 2024/25/2026 cumulative, reference parity; independent recomputation and block6 paired descriptive CIs (not multiple testing adjusted).

## Decision
No promotion if any of: native parity fails, lookahead violation, MAIN/FULL deterioration on either market, FULL max drawdown worsens >3pp, or lack of robust positive increment on genuinely new data. Results of this historical experiment are hypothesis-generating only. No live trade instructions.

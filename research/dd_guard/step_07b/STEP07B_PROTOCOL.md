# STEP07B — ticker-normalized direct action-value / substitution / distributional test

Date: 2026-08-31

## Objective
Test the three remaining high-value DD-controller ideas in one frozen development experiment without using 2023+:
1. direct counterfactual action-value for exposure sizing;
2. substitution into the already-causal monthly satellite instead of cash-only de-risking;
3. distributional (10th-percentile) action-value for left-tail protection.

The economic question is **whether de-risking or substituting today adds value**, not whether a crash label is likely.

## Data identity
- Exact frozen Treatment Value HGB 500-basket daily path (`TREATMENT_VALUE_SELECTED_PATHS.npz`, candidate array) is the untouched base path.
- Frozen official monthly leader/satellite state from `STATE_PANEL.csv`.
- Exact selected Treatment Value substitutions are used only to define the currently held reference ticker when already active.
- OHLCV comes from the self-contained frozen 150-ETF payload embedded in `METEOR_A2_CONFIRM2_SHOCK2_500BASKETS_SELF_CONTAINED.ipynb`.
- STEP07A daily stress-state rows are reused only as the admissible decision times. No 2023+ rows are generated or read for modeling/replay.

## Causality and development split
- Development replay only: 2021-01-01 through 2022-12-31.
- 2021 predictions: training rows whose complete 10-session counterfactual horizon ends no later than 2020-12-31.
- 2022 predictions: expanding training rows whose complete horizon ends no later than 2021-12-31.
- 2023+ remains sealed unless a lane passes the quality-jump gate.
- One market date is the primary evidence unit: sample weights are inverse same-date row count.

## Ticker-normalized state
For the current held reference ticker and the frozen monthly satellite, all features are causal and use only history through decision close:
- 5/10/21/63-session return divided by trailing 63-session volatility times sqrt(horizon);
- 63-session drawdown divided by trailing 63-session volatility times sqrt(63);
- 10/63 volatility ratio;
- 21-session downside-vol / 63-session vol;
- leader-vs-satellite normalized relative momentum and normalized drawdown gap.

Existing STEP07A local normalized basket-path state and three frozen regime coordinates (`sync_rankmean`, `accel_rankmean`, `systemic_rankmean_6`) are included as controls, not searched.

## Counterfactual horizon and execution convention
- Primary counterfactual horizon: 10 sessions, capped at the current monthly exit.
- The decision is observed at close t; counterfactual action starts one full session later (first affected close-to-close return is t+2). This conservative one-session lag avoids assuming unavailable decomposition of the exact base path between close and next open.
- Costs: 5 bp per one-way turnover; temporary counterfactual labels include entry and exit turnover.

## Frozen action sets
### Lane B1 — EXPECTED_EXPOSURE
`HOLD`, `EXPO75`, `EXPO50`, `EXPO25`, `CASH`.

### Lane B2 — EXPECTED_SUBSTITUTION
`HOLD`, `EXPO50`, `SAT50`, `SAT100`, `CASH` where SAT uses the frozen monthly satellite ticker. No new alternative ranker is introduced.

### Lane B3 — Q10_FULL
`HOLD`, `EXPO75`, `EXPO50`, `EXPO25`, `SAT50`, `SAT100`, `CASH`.

## Counterfactual utility
For every state/action:
`utility = 10-session total return + 0.5 * 10-session local MaxDD`, with MaxDD negative.
The 0.5 DD weight is inherited from STEP06L action-value semantics and is not tuned here.

## Models
No estimator grid.
- B1/B2: one HistGradientBoostingRegressor per action, expected utility target.
- B3: one HistGradientBoostingRegressor per action with quantile loss, quantile=0.10.
Frozen hyperparameters: max_iter=160, learning_rate=0.04, max_leaf_nodes=7, min_samples_leaf=35, l2_regularization=8, random_state=20260831.

At each admissible daily state the lane selects the action with highest predicted value. Outside STEP07A stress states the exact base path is untouched. Replay applies the selected action to the following day's return only, then re-evaluates on the next state day. Turnover cost is charged from changes in action weights.

## Quality-jump gate versus frozen FUSION1, 2021–2022
A lane qualifies for one-shot holdout only if all are true:
1. mean MaxDD improvement >= +0.50 pp;
2. p10 MaxDD improvement >= +0.50 pp;
3. CAGR delta >= -0.50 pp;
4. mean MaxDD delta is non-negative separately in both 2021 and 2022;
5. improvement is not generated by a single calendar date: leave-one-date-out worst-case mean-MaxDD delta remains >= 0.

Selection among passing lanes is DD-first: mean MaxDD, p10, then CAGR. If no lane passes, 2023+ stays sealed and STEP07B is rejected.

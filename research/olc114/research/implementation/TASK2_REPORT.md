## API and fixed estimators

`fit_head(X, y, signal_idx, terminal_idx, cutoff, dates, *, min_dates=504, min_months=24, min_blocks=12, n_boot=32, seed=114, penalty=1.)` returns `None` until all three readiness criteria pass. Otherwise it returns `models`, `hashes`, and `meta`. Model names are `MEAN`, `RIDGE`, and `TREE`.

The MEAN estimator is the date-balanced mean. RIDGE uses full-training weighted feature means and population standard deviations, replaces a zero scale with one, leaves the intercept unpenalized, and applies penalty one to weighted mean squared loss. Each bootstrap refits coefficients and intercept in the original training representation. TREE fits raw features using the single prescribed squared-error tree, depth two, minimum leaf weight fraction 0.20, minimum leaf sample count one, and random state 114. All sklearn tree parameters, including fixed defaults, are saved; there is no grid or model selection.

`ValueModel.predict(x)` returns finite `mean` and `lower` floats. The first is the full-training prediction. The second is the linearly interpolated 10th percentile of the 32 bootstrap predictions. It is a heuristic conditional-value buffer, not a calibrated confidence interval.

`ValueModel.to_dict()` and `ValueModel.from_dict()` round-trip complete finite JSON, including full-training fitted parameters, every bootstrap estimator, full-training scaler, fixed estimator parameters, draw provenance, and training identity. MEAN stores numerical values; RIDGE stores intercepts and coefficients; TREE stores children, feature indices, double-precision thresholds and node values. Portable inference converts tree inputs to float32 before threshold comparisons, matching sklearn. Inference does not import sklearn. `training_scaler` returns a detached copy for diagnostics.

## Mature training support and paired blocks

Only rows with `terminal_idx < cutoff` are numerically inspected. Thus a terminal exactly equal to the cutoff is excluded, and mutation of immature features or labels cannot alter an earlier model or draw identity. Mature rows must be finite and have `terminal_idx == signal_idx + 42`.

Every distinct signal date contributes total base weight one, divided evenly among its legs. Readiness counts distinct signal dates, distinct signal calendar months, and greedy nonoverlapping 42-session return intervals. Repeated legs cannot satisfy independent-date readiness.

Root accepted and recorded these implementation conventions before any historical fitting:

1. Return intervals are half-open `[signal_idx, terminal_idx)`. A signal at the previous terminal index shares no return increment and may start the next nonoverlapping interval. The old 21-session counter is not reused.
2. Fixed blocks are occupied absolute panel-index blocks `floor(signal_idx / 63)`, with origin zero. Every replicate samples as many blocks as are occupied, with replacement, using NumPy `default_rng(114)`. The same occupied support produces identical draws across heads even when dates or leg multiplicities inside the blocks differ.
3. Every sampled block retains all rows on its dates. Row weights are date multiplicity divided by that date's number of legs. Estimator losses normalize the resulting total weight. These multiplicities preserve the resampled date distribution rather than erasing repeated-block weights.
4. A mature row with a non-42-session terminal raises `ValueError`; it is not silently admitted or converted to a different horizon.

Metadata exposes `mature_rows`, `mature_dates`, `mature_months`, `nonoverlap_42`, selected nonoverlap signal indices, all admitted signal/terminal indices, raw date-balanced training weights, full-training `scaler` and `feature_scaler`, feature minima/maxima, training hash, exact block support, every bootstrap draw, complete bootstrap specification and draw hash. `max_terminal_idx` allows direct strict-maturity auditing.

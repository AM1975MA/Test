- At each of exactly the same 112 nonoverlapping 21-session anchor dates, select the actual as-of 63-day log price-return Top5 **without future information**. Independent future best ETF already archived only for scoring the *hindsight hit*.
- Construct 250 as-of surrogate five-ETF lists with the **same per-anchor macroclass counts and exact between-anchor number of retained ticker identities** as the original Top5. For every replaced original position, choose a different ticker from the same class whose preceding **63-session daily realized volatility is closest**, sampling from the eight closest eligible alternatives as of prior Close. Surrogates cannot be the original Top5 constituents at that anchor, nor any recently dropped surrogate if that would create a false no-switch. Never see forward returns. Track volatility mismatch and the number of retained names. This controls volatility risk and position turnover as far as possible without duplicating the winner.

# COMPACT21_LEARNER_SWAP_V1

Frozen comparison of canonical Compact21, Ridge and LightGBM LambdaRank on
three raw snapshots. See [PREREGISTRATION.md](PREREGISTRATION.md) for exact
recipes, provenance, qualification rules and unconditional diagnostic replay
scope. [AUDIT.md](AUDIT.md) records independent review and material limits.

This is a research-local replacement of Compact21, including Ridge's
continuous target. The rest of the source-only pipeline, allocation and
negative feedback remain unchanged. No production promotion.

GitHub branch: research/compact21-learner-swap-v1 in AM1975MA/Test.
Results will be retained as results/BENCHMARK.json and results/FULL_REPLAY.json
with all failures visible. MA3 panels and full model/prediction evidence are
retained and compared by semantic values in addition to byte hashes.
